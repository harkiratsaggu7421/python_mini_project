# Python Mini Project

## Project Name
Student Management System

## Introduction
This project is developed using Python and Tkinter. It provides a simple graphical interface for managing student records.

## Features
- Add student details
- View student records
- Search for students
- Update and delete records

## Technology Used
- Python
- Tkinter

## How to Run
1. Install Python on your computer.
2. Open the project folder.
3. Run the main Python file.
